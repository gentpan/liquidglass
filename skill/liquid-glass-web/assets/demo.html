Drag the lens. Text outside it is the original pixels: still selectable, the link still clickable. On the right is the displacement map driving it (R/G = bend, B = highlight).

3. Glass cards over a backdrop

Left: the card holds a copy of the backdrop aligned with it and refracts that — every browser, as long as the backdrop is a known image or graphic. Right: backdrop-filter: url() — real refraction in Chromium only, a blur elsewhere. Both can be dragged.

4. WebGL: video / canvas

Safari never runs SVG filters on a playing <video>, so such surfaces are refracted in WebGL from the same displacement map. A canvas animation stands in for a video here; the API is the same.

Technique after Aave Labs, “Building Glass for the Web”; this page and liquid-glass.js are an independent implementation of the published approach.
